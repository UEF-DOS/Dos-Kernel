# UEF-DOS
## Why?
### Uses 64 bits and not 16
#### The original MS-DOS uses 16 bits and ran on CPUs such as the Intel 8086 and 8088, but today's standards are higher, which means MS-DOS is obsolete — but you should know this already unless you're living under a rock.
### My intentions
#### There's something about MS-DOS and PC-DOS that I admire very much, which is just using the keyboard and typing in commands. Now don't get me wrong, using the mouse is great as well — and it will be needed for some games on DOS — so there will be mouse support. Sadly, since the original games aren't built for 64-bit, we'll have to find ported versions or port our own, which will be time consuming and probably hard.
## Building
### How to build the project
#### Since this uses Limine, it comes with a Makefile. All you have to do is type:
```sh 
make
```
#### Into the command line and you're done — the project will compile!
#### If you would like to run it right after, you can do:
```sh 
make run
```
#### Which will then build and run it for you!
